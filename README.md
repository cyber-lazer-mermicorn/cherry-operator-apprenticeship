# Cherry Operator Apprenticeship

**Structured bridge** into AI, automation, MCP, commerce operations, and the high-level technical lane.

## 1. What this project does
Tracks a capability ladder with real artifacts — not quizzes alone — so Cherry progresses from digital operations through research, GitHub, structured data, AI graphics, commerce, automation, MCP, quality assurance, and deployment.

## 2. Who it is for
Cherry and anyone evaluating her progressive technical readiness.

## 3. What exists today
Foundation structure and ten-module curriculum outline.

## 4. What is planned
Module-by-module real artifacts. Example: take one product, create a valid structured record, validate it, generate a listing, and publish a sanitized case study.

## 5. What it does not claim
Does not claim full-stack developer status or independent production system ownership. It is progressive operator skill building.

## 6. First proof artifact
Completion of Module 01 or 04 with a real, published sanitized artifact.

## 7. Shared Mermicorn services
Consumes the entire core: mega-boot, memory, token-saver, graphic-ai, commerce-ai.

## 8. Information that remains private
Internal progress notes and any personal application materials live in mermicorn-private-ops or the private vault.

---

## Curriculum Outline

```text
01-digital-operations
02-research-verification
03-github
04-structured-data
05-ai-graphics
06-commerce
07-automation
08-mcp
09-quality-assurance
10-deployment
```

Each module ends in a real artifact.
